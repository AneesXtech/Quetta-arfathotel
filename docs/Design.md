# Design & UI/UX Guidelines

## Brand Theme & Aesthetic
Quetta Arfat Hotel captures the vibrant, welcoming late-night dhaba culture of Karachi with a modern, high-end digital aesthetic.

---

## Color Palette
| Token | Hex / Value | Description |
| :--- | :--- | :--- |
| **Primary Brand** | `#8B0000` / `#990000` | Deep Chai Red / Maroon |
| **Accent / CTA** | `#FF4D4D` / `#FF9900` | Warm Flame Red & Saffron Amber |
| **Background Dark** | `#120E0D` / `#1F1614` | Rich Espresso / Dhaba Night Dark |
| **Surface Cards** | `rgba(255, 255, 255, 0.06)` | Frosted Glassmorphism card surfaces |
| **Text Primary** | `#FFFFFF` | Crisp White |
| **Text Muted** | `rgba(255, 255, 255, 0.75)` | Soft Warm Gray / Cream |

---

## Typography
- **Primary Body & Headings**: Modern geometric sans-serif (Inter / System UI / Outfit).
- **Hero & Cultural Accents**: High contrast display typefaces.

---

## UI Components
- **Floating Cart Button**: Real-time counter badge with pulse animation on item add.
- **Glassmorphic Cards**: Delicate 1px borders (`rgba(255,255,255,0.12)`) and background blur filters.
- **Video Banner**: Seamless ambient video player with overlay gradient for high text readability.
